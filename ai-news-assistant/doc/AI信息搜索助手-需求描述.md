# AI 信息搜索助手 — 任务需求描述

## 1. 项目定位

AI 信息搜索助手是 LearnAgent 项目中的**产品化实践项目**：把「多智能体 Agent 流水线 + 可视化报告 + 记忆体系」从教学 Demo 演进为**可交付部署的 Web 产品**。用户输入一句自然语言指令，系统自动规划信息源、并行抓取、综合分析，约 1 分钟产出一份可视化 HTML 报告，并沉淀为长期记忆供后续查询。

## 2. 服务对象

| 角色 | 使用场景 | 核心诉求 |
|---|---|---|
| AI 从业者（开发者 / 研究员） | 跟踪模型发布、开源动态、论文 | 快速获取高质量前沿信息，节省逐站浏览时间 |
| 技术决策者 / 产品经理 | 关注产业资讯与趋势 | 用通俗报告理解行业走向 |
| 个人用户（自部署） | 私有化部署到自己的服务器 | 数据不出本地、按需定制、可控安全 |

定位是**单用户 / 小团队内部工具**，不做多用户账号体系与开放注册。

## 3. 核心任务

一句话指令 → 完整自动化闭环：

```
输入指令 → 安全检测 → 主编规划信息源 → 并行抓取 → 清洗去重
        → AI 综合分析 → 报告大纲 → 可视化 HTML 报告 → 归档 + 记忆沉淀
```

典型指令示例：

- 「抓取本周最新的 AI 前沿动态，重点关注模型发布与产业资讯」
- 「看看最近有哪些值得关注的 AI 论文」

## 4. 功能范围（做什么）

1. **多源信息抓取**：预置 5 个信息源（HuggingFace、arXiv、GitHub Trending、量子位、WIRED AI），按指令自动选择站点、关键词与条数
2. **多智能体流水线**：主编（二阶段规划）、抓取、分析、报告四个 Agent 分工协作，状态机全程可观测
3. **数据质量管道**：清洗、去重、多源交叉提及统计、时间补全、标签提取、停用词过滤
4. **LLM 综合分析**：分类统计、趋势判断、本期速览（TLDR）、自评置信度
5. **可视化报告**：单文件 HTML（图表 / TLDR / 条目卡片 / 搜索 / 打印），含**三级置信度体系**（报告级质量评分、总结级置信度、条目级置信度角标）
6. **记忆体系**：长期记忆（跨任务）、短期记忆（工作 + 会话）、RAG 检索召回历史要点
7. **数据全量保留**：原始抓取数据 + 处理结果 + 报告 HTML + 归档索引
8. **Web 产品化**：首页提交任务、实时日志、最近报告、归档浏览、单密码登录鉴权、健康检查
9. **交付部署**：Docker 镜像 + docker-compose，数据卷持久化，非 root 运行

## 5. 边界（不做什么）

| 边界 | 说明 |
|---|---|
| **不做实时订阅/推送** | 需手动触发任务；如需定时可自行挂 cron |
| **不做并发任务** | 单任务锁，一次只跑一个任务，避免资源争抢与 API 费用失控 |
| **信息源固定** | 预置 5 个站点，技能可扩展但需改代码，不是全网搜索引擎 |
| **不保证抓取完整性** | 外部站点反爬/限流/网络限制可能导致部分来源失败，系统有缓存与超时兜底 |
| **不替代人工判断** | 报告是信息汇总与 LLM 解读，不构成投资、采购或技术选型决策建议 |
| **单用户鉴权** | 仅单密码登录（公网防滥用），无多账号/权限分级/审计日志 |
| **分析质量依赖 LLM** | 置信度体系提供量化参考，但无法保证绝对准确 |
| **不做全文归档检索** | 长期记忆存报告要点摘要（history ≤ 50 条），原始抓取 JSON 保留在 data 目录但不做全文检索引擎 |

## 6. 非功能需求

| 维度 | 要求 |
|---|---|
| 时效性 | 单次任务 ≤ 2 分钟（目标 1 分钟级）；后台线程执行，页面实时反馈日志 |
| 可靠性 | 单点故障不阻塞整体：单站点抓取失败不影响其余来源；任务失败有兜底与错误提示 |
| 可观测性 | 任务状态机 + trace 日志 + Web 实时日志面板 |
| 安全性 | API Key 仅走环境变量、日志脱敏、Prompt 注入检测、可选登录鉴权 |
| 可部署性 | Docker 一键部署，配置全走环境变量，数据卷独立可迁移备份 |
| 可维护性 | 模块化分层（Agent / 数据管道 / 报告 / 记忆 / Web），单测覆盖核心链路 |

## 7. 验收口径

- 三条核心链路可跑通：CLI 任务、Web 任务、RAG 召回历史
- 报告含三级置信度、图表、TLDR、搜索与打印能力
- 数据保留：报告 / 归档 / 记忆在重启与重新部署后不丢失
- 单测回归全绿（test_report / test_pipeline / test_web）
- Docker 部署：`docker compose up -d` 即用，公网可访问（可选鉴权）
